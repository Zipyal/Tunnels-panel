# SSH-туннели

Веб-панель вместо блокнота с командами `ssh -L ...`. Один раз вносите туннели,
дальше: **Подключить** -> **Войти на сайт**. Пароль вводить не нужно.

Работает в Docker: PHP и ssh ставить на компьютер не надо, всё лежит внутри контейнера.

## Что нужно

Только Docker Desktop (Windows / macOS) или Docker Engine (Linux).

Установка на Windows одной командой в PowerShell:

```
winget install -e --id Docker.DockerDesktop
```

После установки перезагрузите компьютер и один раз запустите Docker Desktop
(дождитесь надписи "Engine running").

## Запуск

Windows: двойной щелчок по `start.bat`. Первый раз соберётся образ (1-2 минуты), потом
браузер откроется сам. Остановить: `stop.bat`.

Любая система, из консоли в папке проекта:

```
docker compose up -d --build
```

Панель: http://localhost:8099

Контейнер стоит с `restart: unless-stopped`, то есть после перезагрузки компьютера
панель поднимается вместе с Docker. Туннели после перезагрузки нужно подключить заново
(кнопка "Подключить все").

## Первое использование

1. Нажмите **Импорт**.
2. Вставьте команды из блокнота, по одной на строку:
   ```
   ssh -f -N -L 1111:11.11.1.11:222 login@333.333.33.33 -p22
   ```
   или сразу с названием, паролем и ссылкой:
   ```
   CRM | ssh -f -N -L 1111:11.11.1.11:222 login@333.333.33.33 -p22 | пароль | localhost:222
   ```
3. Пароль и ссылку можно дописать позже кнопкой ✎.

## Порты (важно)

Контейнер открывает на вашем компьютере диапазон портов, по умолчанию **1100-1199**.
Число после `-L` в каждой команде (локальный порт) должно в него попадать.
Если не попадает, панель покажет жёлтое предупреждение.

Чтобы поменять диапазон:

```
copy .env.example .env      (Linux/macOS: cp .env.example .env)
```

В `.env` поправьте `TUNNEL_PORTS`, например `TUNNEL_PORTS=3000-3199`, и перезапустите
(`docker compose up -d`). Не делайте диапазон больше 200 портов.

## Вход по ключу

Положите файл ключа в папку `keys/` и оставьте пароль пустым. В команде путь можно
писать как угодно (`-i C:\Users\me\.ssh\id_rsa`), панель возьмёт только имя файла.

## Если что-то не работает

Красная строка под туннелем - это ответ ssh:

| Сообщение | Причина |
|---|---|
| `Permission denied` | неверный логин или пароль |
| `Address already in use` | порт уже занят другой программой на компьютере |
| `Connection timed out` | сервер не отвечает (нужен VPN?) |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | сервер пересоздали; удалите его строку из `data/known_hosts` |

Логи контейнера: `docker compose logs -f`.

## Безопасность

- Панель и туннели слушают только `127.0.0.1`, из локальной сети они недоступны.
- Пароли лежат открытым текстом в `data/tunnels.json`. Не отправляйте папку `data` и не
  кладите её в git (она в `.gitignore`).
- Панель отвечает только на запросы к `localhost` и только со своим заголовком,
  чтобы чужие сайты в браузере не могли ею управлять.

## Как устроено

```
app/index.php        точка входа: роутинг, проверки
app/src/Api.php      обработчики /api/*
app/src/Tunnels.php  запуск и остановка ssh, статусы
app/src/SshCommand.php  разбор строки ssh
app/src/Store.php    хранение в json (с блокировкой)
app/public/          интерфейс: index.html, style.css, app.js
docker/              entrypoint и askpass
```

Статусы берутся из `/proc` (один файл вместо опроса каждого порта), интерфейс
опрашивает сервер раз в 5 секунд, а пока идёт подключение, раз в секунду.
Вкладка в фоне не опрашивает вообще.
