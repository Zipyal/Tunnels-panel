SSH-ТУННЕЛИ — панель кнопок вместо блокнота
===========================================

Что это
-------
Одна страница в браузере. Вы один раз вносите свои ssh-подключения
(команда, пароль, ссылка), а дальше всё делается кнопками:
«Подключить» -> «Открыть». Пароль вводить и копировать не нужно.


ЗАПУСК НА WINDOWS
-----------------
1. Распакуйте архив в любую папку (например, на рабочий стол).
2. Дважды щёлкните по файлу  start.bat
   - Если PHP не установлен, окно само установит его командой winget
     (встроен в Windows 10/11). После этого закройте окно и запустите
     start.bat ещё раз.
3. Откроется браузер с панелью. Окно с чёрным фоном не закрывайте,
   пока работаете.

Если дважды щёлкнуть неудобно, можно открыть консоль в папке и ввести:
    php tunnels.php


ЗАПУСК НА macOS / LINUX
-----------------------
В консоли, в папке с файлами:
    sh start.sh
(при первом запуске само поставит PHP через brew/apt/dnf)


ПЕРВОЕ ИСПОЛЬЗОВАНИЕ
--------------------
1. Нажмите «Импорт».
2. Вставьте свои команды из блокнота, по одной на строку. Можно так:
     ssh -f -N -L 1111:11.11.1.11:222 login@333.333.33.33 -p22
   или сразу с названием, паролем и ссылкой:
     CRM | ssh -f -N -L 1111:11.11.1.11:222 login@333.333.33.33 -p22 | мойпароль | localhost:222
3. Нажмите «Импортировать». Если не указали пароль или ссылку,
   их можно дописать через кнопку ✎ у нужного туннеля.

Дальше каждый день:
  - «Подключить» у нужной строки (кружок станет зелёным)
  - «Войти на сайт» откроет вашу ссылку
  - «Стоп» отключает туннель
  - 🔑 копирует пароль, 🔗 копирует ссылку
  - «Подключить все» / «Отключить все» работают сразу для всех


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- Красная строка под туннелем — это ответ сервера. Частые случаи:
    "Permission denied"       неверный пароль или логин
    "Address already in use"  этот порт уже занят (туннель уже запущен)
    "Connection timed out"    сервер недоступен (нужен VPN?)
- "php не найден": закройте окно и запустите start.bat снова
  (после установки Windows должен «увидеть» PHP).
- Порт панели 8099 занят: php tunnels.php 9000
  (панель откроется на http://127.0.0.1:9000)


ВАЖНО
-----
- Пароли хранятся открытым текстом в папке tunnels-data рядом с
  программой. Не пересылайте эту папку и не публикуйте её.
  Другому человеку отправляйте только tunnels.php, start.bat, start.sh
  и этот файл.
- Панель доступна только на вашем компьютере (127.0.0.1), из сети
  её не видно.
- Нужен OpenSSH 8.4 или новее (проверка: ssh -V).
  На Windows 10/11 он обычно уже есть.
